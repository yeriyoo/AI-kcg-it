GitHub npm v2.9.0

📘 kordoc — Korean Document Parser

한국 공무원이 7년 이상 정부 문서 작성 경험을 바탕으로 만든 종합 문서 파서. 한컴 HWP 전 버전(3.x/5.x/HWPX/HWPML) + PDF/XLSX/DOCX를 Markdown으로 변환하며, 병합 셀·중첩 표·이미지·OCR·DRM 문서까지 지원합니다. AI Agent와 MCP(Model Context Protocol)로 직접 연동되어 RAG 지식베이스·NLP 학습 데이터 구축에 즉시 활용 가능합니다.

지원 포맷 (8종)

HWP 한컴 5.x 표준 (정부·공공 표준)
HWPX 한컴 2020+ ZIP/XML 기반
HWP3 한컴 3.x 레거시 (1996~2002)
HWPML 한컴 XML 포맷
PDF OCR 지원 (이미지 PDF)
XLSX Microsoft Excel
XLS Excel 97-2003
DOCX Microsoft Word

MCP AI Agent 통합

8종 MCP 도구 — Claude/Cursor 등 직접 연동

파이프라인 — 한글문서 → 학습데이터

1

업로드

한글 문서(.hwp/.hwpx) 등을 드래그&드롭 또는 선택

2

파싱

kordoc 엔진이 IR(Intermediate Representation) 블록 생성

변환

활용

AI 학습데이터셋(NLP/RAG) · 법령 코퍼스 · RPA 자동화

🚀 직접 파싱해보기 (브라우저)

업로드한 파일은 브라우저 내에서만 처리되며 서버로 전송되지 않습니다. 현재 화면은 파일 선택 데모입니다. 한컴 .hwp/.hwpx, PDF, DOCX, XLSX 등을 시험해보세요.

클릭하거나 파일을 드래그하세요 .hwp · .hwpx · .pdf · .docx · .xlsx · .xls · .hwpml · .hwp3
파일 선택 완료 · 파싱 엔진 미연결

📝 통합 코드 예시

🧩 브라우저 / Node.js 
import { parse } from 'kordoc';
import { readFileSync } from 'fs';

const buffer = readFileSync('document.hwpx');
const result = await parse(buffer.buffer);

if (result.success) {
  console.log(result.markdown);   // Markdown 텍스트
  console.log(result.blocks);     // IRBlock[] 구조화 데이터
  console.log(result.metadata);   // 제목·작성자·일자
}
🧩 CLI (npx) 
# 단일 파일 변환
npx kordoc document.hwpx > document.md

# 폴더 일괄 변환 (watch 모드)
npx kordoc --watch ./hwp-input ./md-output

# MCP 연동 (Claude Desktop · Cursor 등)
npx -y kordoc setup
# → 8종 MCP 도구가 AI 에이전트에 등록됨

🚢 해경 적용 사례

법령 RAG 코퍼스 구축

해양경찰청·수산업법·EEZ법 등 법령 HWP/PDF를 Markdown으로 변환 → SFR-19 생성형 AI Q&A 지식베이스 자동 적재

단속·사고 보고서 NLP

단속 보고서 HWP 일괄 파싱 → NER·분류 모델 학습데이터 (RPT-CLS · DAR-01) → 비식별화는 KCG-POL-003 별도 적용

내부 지침·매뉴얼 정제

KCG-POL 시리즈·운영매뉴얼 → 정제(refined) 단계 자동 입력 → 학습데이터셋 버전 관리(DAR-05)

시방서·계약서 비교

문서 Diff 기능 활용 → 입찰 시방서 개정 이력 자동 추출 + 변경관리 절차(PMR-08) 연계

서식 자동 채우기

신청서·보고서 표준 양식에 단속 메타데이터를 자동 채워 발급 → 모바일·함정 Agent UI에서 호출

MCP AI Agent 연동

함정 Agent(SFR-16) MCP 게이트웨이에 kordoc 8 tools 등록 → “이 보고서 요약해줘” 자연어 명령 처리
