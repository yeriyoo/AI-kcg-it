오염탐지

항공·드론 영상 기반 해양 유출유 세그멘테이션 — 클래스별 면적·두께 산정

탐지 실행 탐지 알고리즘 학습 학습 결과 참고자료

수면 분리 → 세그멘테이션 → 면적·두께 산정 4단계 + 표류·확산 연계 설계

처리 흐름

입력: 항공·드론·CCTV 영상 1 수면 영역 분리 – 시점별 분기 2 유출유 세그멘테이션 3 등급별 면적·두께 집계 4 실면적 환산·표류 연계
인스턴스 분할 vs 의미 분할

현재 모델은 의미 분할이라 클래스 맵만 나오고 유막 덩어리 구분이 없다. 그래서 덩어리 개수·최대 면적·포위선은 포스트에서 연결요소 분석으로 따로 계산한다. YOLOv8-seg 같은 인스턴스 분할은 이걸 모델이 바로 내주고, 일자간 미탐 시 아무것도 출력하지 않을 수 있다는 차이도 있다. 의미 분할은 모든 화소에 클래스를 강제 배정한다.

핵심은 수면 분리를 세그멘테이션 앞단에 두는 것이다. 유막은 어두운 저반사 영역으로 나타나 그림자·짙은 갯벌·연무와 색이 비슷하다. 뒤에서 걸러내는 것보다 탐지 대상에서 빼는 편이 오탐이 적다.

1단계

수면 영역 분리 — 시점별 분기

구현

입력

항공·드론·CCTV 프레임 (RGB)

도구

OpenCV 수평선 검출 / 색조 기반 nadir 판별

처리

  1. CCTV(사각): 수평선 검출로 하늘·육상 제거, 실패 시 하단 전체를 수면으로 간주
  2. 드론(직하방): 수평선이 없으므로 색조·텍스처로 수면 판별
  3. 요청의 view 파라미터로 선택 — 드론 영상을 CCTV 방식으로 보내면 상단 대부분이 잘려나간다

산출

수면 이진 마스크 (0=비수면, 1=수면)

2단계

유출유 세그멘테이션

구현

입력

수면 마스크 + 원본 프레임

도구

mmsegmentation · PyTorch

처리

  1. mmsegmentation 모델로 화소 단위 유막 클래스 분류
  2. softmax 송자확률이 임계값(OIL_CONF_MIN) 미만인 오일 화소는 배경으로 환원
  3. 수면 외 화소를 0으로 강제 — 후처리가 아니라 판정 자체에서 배제
  4. Bonn 외관 코드 4등급 분류 (검정·갈색·무지개·은색)

산출

클래스 맵 (1픽셀 = 1 classId)

3단계

등급별 면적·두께 집계

구현

입력

클래스 맵

도구

집계 로직 (api.py)

처리

  1. 클래스별 화소수 → 전체 화소 대비 비율
  2. 유막 색상 등급 → 두께(mm) 매핑 (Bonn Agreement 색상-두께 코드 계열)
  3. 유출량 추정은 면적 × 두께 — 두 값의 불확실성이 곱해진다

산출

클래스별 픽셀수 · 비율 · 추정 두께

4단계

실면적 환산 · 표류 연계

부분구현

입력

비율 + 촬영 메타데이터

도구

변환 역투영 · OpenDrift/OpenOil(예정)

처리

  1. 행별 지상축척 산출 — 고도·부각·화각으로 픽셀 광선을 해수면과 교차 (CCTV·드론 구형)
  2. 직하방(부각 90°)은 화면 전체 축척이 균일해져 부각 오차 민감도가 ±18% → ±1.5%로 떨어진다
  3. 화소 마스크 → 실면적(m²) 및 등급별 두께를 곱한 추정 유출량 (CCTV 구현)
  4. 탐지 유막을 라그랑지 입자로 seeding — 유출량 추정치에 비례해 입자 배분 (미구현)
  5. 이송장 = 조류 + 취송류(V=0.029·Vw, θ=θw+18.6°) + Stokes drift (미구현)
  6. fBm 난류확산 · 풍화(증발·유화)로 잔존량 갱신 (미구현)

산출

실면적 · 추정 유출량 (구현) → 시계열 표류 확산 예측 (미구현)

4단계 표류·확산 연계 설계

탐지는 지금 어디에 얼마나 있는가만 답한다. 방제 판단에는 앞으로 어디로 가는가가 필요하다. 아래는 국내 KOSPS 계보와 OpenOil 물리 원전에 정리한 설계 근거다.

이송장 (어디로 가는가)

조류 — 실시간 예측 결합이문진·강용문 외 (2008) · 류정호 외 (1998)

CHARRY 또는 harmonic method로 창조·낙조를 실시간 재현해 이송장에 더한다. 연안 유출은 조류가 지배적이라 조류 없이 바람만 쓰면 방향이 반대로 나올 수 있다. 반대로 조류가 약한 해역(부산·울산 주변)에서는 취송류·해류가 지배하므로, 해역에 따라 어느 항이 지배적인지가 달라진다.

취송류 — 국내 관측 경험식이문진·강용문 (2000)

V=0.029·Vw, 편향각 θ=θw+18.6°. 풍동되는 "풍속 3%" 어렵게 크기는 비슷하지만 편향각이 관측으로 고정된다는 점이 다르다. 국내 연안 현장 관측에서 도출돼 우리 해역에 바로 쓸 수 있다.

Stokes drift — 파랑 기여Röhrs et al. (2013)

파랑의 비선형 효과로 표면 부유물이 파 진행 방향으로 밀리는 성분. 현장 검증에서 이 항을 빼면 궤적 오차가 커진다. 조류+바람만으로는 부족하다는 뜻이다.

난류확산 — fBm이문진·김혜진 (2009)

입자에 프랙털 브라운 운동을 더해 유막 퍼짐을 모의한다. 단순 랜덤워크와 달리 시간 상관을 가져, 실제 유막처럼 길게 늘어지는 형태가 재현된다.

풍화 (유막이 어떻게 변하는가)

퍼짐 — Fay 3단 이론Fay (1969)

중력-관성력 → 관성력-점성력 → 표면장력-점성력 순으로 지배 힘이 바뀌며 퍼진다. 유출 직후와 수 시간 뒤의 확산 속도가 다른 이유이고, 초기 면적 설정을 계산하는 원전이다.

증발 — Stiver·Mackay 해석모델Stiver & Mackay (1984)

유종별 증류 곡선으로 증발비를 산정한다. 경질유는 초기 수 시간에 상당량이 날아가므로, 증발을 안 넣으면 잔존량을 과대 추정해 방제 물량이 부풀려진다.

유상화 · 소산 — Mackay 모델Mackay et al. (1980)

water-in-oil 유상화로 점도·부피가 늘고 회수 난도가 올라간다. 소산은 유막을 수중으로 분산시킨다. 탐지 화면의 두께 등급이 시간에 따라 왜 변하는지를 설명하는 항이다.

운용 (예측을 판단으로)

3차원 확장 — 침강·혼합이문진 외 (2013) · Nordam et al. (2019)

수면 2D 추적에 침강·혼합효과를 더한 3D 모델. 해비에 스피리트호 720시간 적용으로 검증됐다. 수직 분포와 해저면 도달 경로까지 봐야 해안·저서 피해를 다룰 수 있다.

통계 위험도 — Monte Carlo이문진·김혜진 (2009) · 김혜진·이문진 (2008)

20년 과거 기상·조류 자료로 100~200회 반복 모의해 해안·어장별 도달확률과 도달시간을 낸다. 단일 궤적은 예측이 아니라 확률로 내야 방제자원 사전 배치 근거가 된다.

방제효과 모델링이문진 외 (2014)

오일펜스 누유율, 유처리제 분산에 따른 확산면적 변화, 유회수기 회수에 따른 해상 분포량 변화를 각각 모델화해 확산예측에 통합한다. "방제하면 어떻게 달라지는가"를 답하는 부분이다.

구현 기반 — OpenDrift / OpenOilDagestad et al. (2018)

Python 모듈형 궤적 모델 프레임워크로, 유출유 모듈(OpenOil)에 위 항과 3항과 Stokes drift가 이미 들어 있다. 물리를 처음부터 짜는 대신 이송장(국내 조류·취송류)만 주입하는 편이 검증 부담이 적다.

격자 보간 — Akima quinticAkima (1974·1978)

수심·수온·해류 격자를 입자 위치로 보간할 때 쓰는 2차원 5차다항식 국소 보간. 선형 보간은 격자 경계에서 유속이 꺾여 입자가 비물리적으로 튀는데, 이를 피한다.

이 연계는 검증 루트도 만든다. 해비에 스피리트호 검증이 RadarSat 위성영상과 예측 유막을 비교한 방식인데, 지금 이 탐지 모듈이 바로 그 관측 유막을 만들어낸다. 즉 탐지→표류예측의 입력에서 동시에 검증 데이터 공급자로도 쓰일 수 있다.
