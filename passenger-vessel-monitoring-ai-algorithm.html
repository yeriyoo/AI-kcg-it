AI 알고리즘

여객선 종합 위험정보 모니터링 — AIS + 기상·해양정보 · 실시간 위험 탐지 · 30분 후 위험 예측
개요 AIS모델위험도 탐지알고리즘 시나리오 학습 참고자료 분석 성능·평가
위험요인 5종 기상 · 충돌 · 항로 · 운항패턴 · AIS품질
예측 구간 30분 +5 · 10 · 15 · 20 · 30분
위험등급 4단계 정상 · 관심 · 주의 · 경계
적용 규칙 기반 「분석」 탭 지도에 실시간 적용

설계 목표 및 기본 방향

본 알고리즘은 여객선의 AIS 위치·속력·침로와 기상·해양정보를 실시간으로 융합하여, 현재의 위험뿐 아니라 향후 30분 이내 발생할 가능성이 있는 위험 징후를 사전에 탐지하는 것을 목표로 합니다.

분석 대상 내용
기상·해상 위험 풍속, 파고, 시정, 조류 등으로 인한 운항 위험
항로·운항 위험 비정상적인 항로 변경, 급감속, 장시간 정지
충돌 위험 주변 선박과의 상대 거리, 접근 속도, CPA/TCPA
위치정보 위험 AIS 신호 단절, 위치 점프, 비정상 속도
복합 위험 여러 위험요인이 동시에 발생하거나 짧은 시간 안에 악화되는 상황
중요한 설계 원칙은 위험점수만 계산하는 것이 아니라, 위험 원인 · 위험 발생 예상시간 · 데이터 신뢰도 · 경보 조치를 함께 산출하는 것입니다.

처리 흐름

단계 처리 내용
① 입력 데이터 AIS 위치·속력·침로 + 기상·해양 관측 및 예보
② 시간·공간 정합 및 데이터 품질 검사 시간 동기화 · 위치 보정 · 결측·이상치 확인
③ 환경 위험 엔진 / 운항 위험 엔진 풍속·파고·시정·조류 / 충돌·속력·침로·신호
④ 30분 예측 및 위험도 융합 현재 위험 + 미래 위험 + 위험 증가 추세 + 데이터 신뢰도
⑤ 위험등급·경보·GIS 시각화 선박별 점수 · 위험 원인 · 예상 시점 · 경보 이력

적용 현황

설계서 알고리즘을 운항 중 여객선에 적용해 「분석」 탭 지도에 선박별 종합 위험도 · 30분 예측 · 경보를 표출합니다. 요인별 입력은 다음과 같습니다.

위험요인 입력 데이터 비고
기상·해상 위 (25%) 예보 격자(0.5°·1시간) 풍속·파고 시정·조류 자료 없음 → 결측으로 빼고 재정규화
충돌 C (30%) 주변 6NM 실시간 AIS — CPA/TCPA 항로 기준 — 자신 예상 항로와 상대선 항로로 30분 최근접 산출, 다가오는 앞쪽 선박만(옆·뒤·멀어지는 선박 제외), 정박·묘박·비정상·6분 넘게 끊긴 신호 제외, 항내(항구 0.5NM) 평가 제외
항로·운항 이상 N (20%) 직전 표본 대비 선회율·감속률 계획 항로 없음 → 대체 지표, 화면을 연 뒤 쌓인 표본만 사용
비정상 운항 패턴 O (15%) 오늘 운항한 운항 상태 모든 표본이 통제·비운항인데 운항 중이면 가점
AIS 데이터 이상 D (10%) 수신 지연·불가능한 속력 수신 지연이 길면 데이터 신뢰도도 낮춤

임계치는 설계서의 테스트용 값입니다. 선박·항로별 운항기준을 확인하기 전에는 실제 안전 경보로 쓰지 않습니다.

필수 전제

AIS만으로는 여객 정원, 적재 상태, 선박 안정성, 기관 상태 등 모든 안전요소를 알 수 없습니다. 따라서 본 설계는 AIS와 기상·해양정보 기반의 위험 징후 탐지 체계이며, 실제 운항 허용 여부를 결정하는 법정 안전판정 체계를 대체하지 않습니다.

최종 권고

현재 조건에서는 규칙 기반 위험 탐지 + 30분 항적 예측 + 기상·해양 예보 결합 + 위험도 융합을 첫 번째 구현 목표로 설정하는 것이 좋습니다. 머신러닝은 충분한 과거 사례와 검증된 라벨이 확보된 후 추가하는 편이 안전합니다.

다음 세 가지가 실제 구현을 시작하기 위한 핵심 입력입니다.

  • AIS 데이터 형식: 실시간 API, CSV, NMEA 원문 중 어떤 형식인지
  • 기상·해양정보 출처: 예보 격자, 관측소, API 또는 자체 DB 중 어떤 데이터를 사용하는지
  • 여객선 운항기준: 선박별 운항 제한, 계획 항로 및 정상 운항 기준을 확보할 수 있는지

이 정보가 확정되면 데이터 수집부터 위험 산정, 30분 예측, PostgreSQL 저장, REST API 제공까지 연결할 실행 가능한 Python MVP로 구체화할 수 있습니다.
