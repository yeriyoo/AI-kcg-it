📕 opendataloader-pdf — Open-source PDF Parser

PDF 문서를 JSON(bounding box·시맨틱 요소 타입)·Markdown·HTML·Text로 구조화 추출하는 오픈소스 파서입니다. 복잡한 표·다단 레이아웃의 읽기 순서를 복원하고, 태그가 없는 PDF를 접근성(PDF/UA) Tagged-PDF로 자동 변환합니다. Java 11+ 기반 엔진에 Node·Python·Java 바인딩을 제공하며 RAG 지식베이스·NLP 학습 데이터 구축에 활용할 수 있습니다. (Apache License 2.0)

출력 포맷 (5종)

JSON bounding box 좌표 + 시맨틱 요소 타입
Markdown LLM 컨텍스트 · RAG 최적화
HTML 웹 표시용 구조 보존
Text 순수 텍스트 추출
Tagged-PDF 접근성(PDF/UA) 자동 태깅

🚀 직접 파싱해보기

업로드한 PDF는 서버의 opendataloader-pdf 엔진으로 전달되어 JSON·Markdown으로 변환됩니다. (서버에 Node 20+ · Java 11+ 필요) 현재 화면은 파일 선택 데모이며 서버 전송은 하지 않습니다.

클릭하거나 PDF 파일을 드래그하세요 .pdf
파일 선택 완료 · 파싱 엔진 미연결

📝 통합 코드 예시

🧩 Node.js 
import { convert } from '@opendataloader/pdf';

// outputDir에 .md / .json 결과 파일 생성
await convert(['document.pdf'], {
  outputDir: 'output/',
  format: 'markdown,json',
});
🧩 CLI (npx) 
# 단일/다중/폴더 변환
npx @opendataloader/pdf document.pdf -o output/ -f markdown,json

# 접근성 Tagged-PDF 생성
npx @opendataloader/pdf document.pdf -f tagged-pdf

# 복잡 표 정확도 향상 (hybrid)
npx @opendataloader/pdf --hybrid docling-fast document.pdf

🚢 해경 적용 사례

법령·고시 PDF RAG 코퍼스

해양경찰법·수산업법·EEZ 관련 법령/고시 PDF를 JSON·Markdown으로 구조화 → SFR-19 생성형 AI Q&A 지식베이스 적재

스캔 보고서 구조화

단속·사고 보고서 스캔 PDF의 레이아웃·표를 복원 → NER·분류 모델 학습데이터(RPT-CLS · DAR-01) → 비식별화는 KCG-POL-003 별도 적용

시방서·계약서 표 추출

입찰 시방서·계약서 PDF의 복잡 표를 hybrid 모드로 정확 추출 → 변경관리(PMR-08) 연계

접근성 PDF 변환

대국민 공개 문서를 Tagged-PDF(PDF/UA)로 자동 변환 → 웹 접근성 준수

외부 문헌 정제

연구보고서·논문 PDF를 정제(refined) 단계 자동 입력 → 학습데이터셋 버전 관리(DAR-05)

다국어/혼합 문서

읽기순서 복원 + invalid 문자 치환으로 표·다단 혼합 PDF의 텍스트 품질 확보
